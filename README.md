# ApiconIASIS: Bee Wanderer

A pixel-art educational game prototype made for a competition / hackathon. Flora travels through bee habitats, collects cure ingredients, avoids infected bees, and learns about pollinators.

## Play / project links

- https://iasonkz.github.io/EU_CONEXUS_Hackathon/
- https://iasonkz.github.io/Plan_Produce_Play/

## How to run locally

Open `index.html` in a browser, or serve the folder with a simple local web server and open the project root. The initial PLAY screen appears on fresh loads/reloads, then opens the globe lobby.
